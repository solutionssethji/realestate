# Required Client Inputs Checklist

The following assets and credentials are required from the client for final production deployment:

- [ ] Client logo, colors, and branding guidelines
- [ ] Final Project & Plot data
- [ ] Site layout images/assets
- [ ] 360° videos for projects
- [ ] Payment Gateway credentials (API Keys, Secrets)
- [ ] Google Maps API credentials
- [ ] Hosting/Server details for Backend and Admin deployment
- [ ] Play Store / App Store credentials
- [ ] Initial admin email/password preferences
- [ ] Firebase configuration (if required for push notifications)
